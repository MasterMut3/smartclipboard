# Smart Clipboard v1.0.0 Release Notes

## 🎉 First Official Release!

### 📦 What's Included

#### Two Versions:

1. **Installer Version** (`SmartClipboard-Setup.exe`)
   - Regular Windows installation
   - Adds to Start Menu
   - Optional Windows startup
   - Data in `%USERPROFILE%\.smart_clipboard\`

2. **Portable Version** (`SmartClipboard-Portable.zip`)
   - No installation needed
   - Run from USB drive or any folder
   - Data stored next to the .exe
   - Perfect for work/school computers

### ✨ Features

- 📋 **Real-time Clipboard Monitoring** - Automatically detects copied text
- 🏷️ **Smart Naming** - Add names and tags to saved items
- 🔍 **Search History** - Find anything you've copied
- 💾 **Export/Import** - Backup and restore your data
- ⚡ **Quick Export** - One-click save to Desktop
- 🖥️ **System Tray** - Runs quietly in background
- 🎨 **Clean Interface** - Easy to use

### 🚀 How to Use

#### Installer Version:
1. Run `SmartClipboard-Setup.exe`
2. Follow installation wizard
3. App starts automatically

#### Portable Version:
1. Extract `SmartClipboard-Portable.zip`
2. Run `SmartClipboard-Portable.exe`
3. Start copying text!
